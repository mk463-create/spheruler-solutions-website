AccuPan
AccuPan web tool gives an intuitive response in interactive viewing of 360-degree panorama images.

Drop a panorama (equirectangular) image to check:
* Accurate panning of scene as per the user control.
* Faithful zooming about the user chosen point.
* Sensible rotations at zenith/nadir zones.
* Rebound to un-slanted, upright state at limits.

Easy to integrate to html page with a single JS call.
