# Spheruler Solutions Website

Website development and redesign project for Spheruler Solutions Pvt. Ltd.

## Overview

This repository contains the development files for the Spheruler Solutions website, including website pages, styling, and interactive visual elements.

## Technologies

- HTML
- CSS
- JavaScript
- Three.js
- Canvas API

## Features

- Responsive website layout
- Custom navigation
- Interactive visual elements
- Animated star-field background
- Nebula and planetary background effects
- Three.js 3D elements
